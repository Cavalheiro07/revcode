# RevCode

Jogo diário de revisão de código em Python: todo dia, todos os jogadores recebem o mesmo trecho de código, que
funciona, mas tem problemas de legibilidade e manutenção (clean code), e apontam a linha e a categoria de cada um.

Este repositório reconstrói, módulo a módulo, o RevCode criado no Projeto Integrador VI (Engenharia de Software,
2026), aplicando as práticas da disciplina de arquitetura: decisões de arquitetura registradas em ADRs, princípios
SOLID, Clean Code e padrões GoF. Toda mudança entra por pull request revisado.
